為什麼做這個網站？

學 Python 時，錯誤訊息常常看得懂單字，卻不知道該從哪裡修改。PyNotes 把常見問題整理成固定格式，讓讀者可以先看錯誤、理解原因，再練習修正。網站也有一份 AGENTS.md，規定未來新增文章的格式與流程，讓內容能持續擴充。

本站使用純 HTML、CSS 和 JavaScript 製作，不需要登入或 API 金鑰。程式碼範例以 Python 3 為準。
