ZeroDivisionError：除數不能是零

看懂錯誤訊息，再試著自己修正。

1. 問題介紹

Python 在進行除法時，如果除數為零，就會出現 ZeroDivisionError。

2. 錯誤範例

total = 100
count = 0
print(total / count)

執行時會看到的主要錯誤訊息：

ZeroDivisionError: division by zero

3. 錯誤原因

除法的除數不能是 0。當除數來自使用者輸入或計算結果時，應先確認它是否為零。

4. 修正方法

total = 100
count = 0
if count != 0:
    print(total / count)
else:
    print("無法除以零")

5. 自己練習

請讓 a = 12、b = 0 的除法程式，在 b 為 0 時顯示提醒。

點我查看參考解答
a = 12
b = 0
if b == 0:
    print("除數不可為零")
else:
    print(a / b)
