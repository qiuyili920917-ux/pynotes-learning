TypeError：字串與整數相加

看懂錯誤訊息，再試著自己修正。

1. 問題介紹

當程式對不相容的資料型態進行運算時，可能出現 TypeError。例如字串與整數不能直接使用 + 連接。

2. 錯誤範例

age = 20
print("Age: " + age)

執行時會看到的主要錯誤訊息：

TypeError: can only concatenate str (not "int") to str

3. 錯誤原因

"Age: " 是字串，age 是整數。Python 不會在這種加法中自動把整數轉成字串。

4. 修正方法

age = 20
print("Age: " + str(age))
# 或 print(f"Age: {age}")

5. 自己練習
